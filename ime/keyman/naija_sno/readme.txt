Naija SNO (Keyman)
==================

IFRA/NLA Standard Naijá Orthography digraphs and high-tone acute vowels.

Digraphs (type first letter, then second):
  gb  kp  sh  ch  zh

High tone: type apostrophe then a e i o u  →  á é í ó ú

Word suggestions use naija_sno.wordlist.tsv regenerated from the Live Dictionary
IME export (python data/export_keyman_wordlist.py).

This package does not modify the Live Dictionary.
