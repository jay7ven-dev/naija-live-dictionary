Start the site

From the project folder run python web/serve.py. The default page is Fix spelling (http://localhost:8765/web/normalize.html). Dictionary search is at index.html. Opening HTML directly from disk will not load dictionary data.

Search (dictionary)

  1. Open Dictionary search.
  2. Type a word — standard SNO or an informal spelling.
  3. If your query is an informal form, a banner shows the mapping to the standard headword.
  4. If nothing matches exactly, a “Did you mean?” spelling suggestion may appear (close spellings). This is not full autocorrect.

Tools (do not mix them up)

ToolUse whenWhat it does
Fix spelling (primary) The text is already Pidgin with messy spelling Token spelling → SNO via the dictionary index (rules) — does not rewrite English grammar
Dictionary search You want one word or variant Looks up SNO headwords and informal → standard mappings
English → Pidgin (Advanced on Fix spelling page) You have an English sentence Optional local Marian MT, then SNO spelling — MT alone is not IFRA authority
Keyman (Naija SNO) You type in other apps System keyboard: digraphs + acutes; see ime/keyman/naija_sno/

Example: English I want to see you belongs under Advanced: English → Pidgin. Pasting it into Fix spelling alone may leave English words unchanged.
