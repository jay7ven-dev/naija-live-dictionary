Start the site

From the project folder run python web/serve.py, then open http://localhost:8765/web/. Opening the HTML file directly from disk will not load dictionary data.

Search

  1. Type a word in the search box.
  2. You can use a standard spelling (IFRA/NLA SNO) or an informal spelling.
  3. If your query is an informal form, a banner shows the mapping to the standard headword.
  4. If nothing matches exactly, a “Did you mean?” suggestion may appear (close spellings).

Try these

  • pickin → pikin
  • book → buk
  • dey → progressive/locative family
  • shey → abi

Three tools (do not mix them up)

ToolUse whenWhat it does
Dictionary search You want one word or variant Looks up SNO headwords and informal → standard mappings
English → Pidgin You have an English sentence Converts meaning to Pidgin (local model), then applies SNO spelling
Fix spelling only (on that same page, under the details panel) The text is already Pidgin with messy spelling Token spelling → SNO via the dictionary index — does not rewrite English grammar

Example: English I want to see you belongs on English → Pidgin (sentence conversion). Pasting it into spelling-fix alone may leave English words unchanged.
