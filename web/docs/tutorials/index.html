Tutorial A: Informal → standard lookup

  1. Start the server (User Guide).
  2. Search pickin.
  3. Confirm the banner maps to pikin and the card shows “child”.
  4. Repeat with book → buk.

Tutorial B: Fuzzy suggestion

  1. Type a near-miss spelling that is not in the exact index.
  2. If no exact/substring hit, check for a “Did you mean?” control.
  3. Click the suggestion to load the standard entry.

Tutorial C: Curate one variant (contributors)

  1. Run python data/collect_variants.py suggest.
  2. Inspect candidates in data/suggestions.json (pending only).
  3. Add only human-verified rows via curate_mappings.py or variant_mappings.json.
  4. Run apply → index → validate → web/verify.py (see Reproducibility).

Warning: English words in code-switched speech often look like “variants” but are false positives. Prefer low volume, high confidence.

Tutorial D: Export for research tools

  1. Run python export/tei_lex0.py.
  2. Open export/naija-dictionary.lex0.xml.
  3. Cite using docs/citation-pack.md.
